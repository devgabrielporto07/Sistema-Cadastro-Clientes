# Sistema de Cadastro de Clientes

Aplicação em Python para cadastro e gerenciamento de clientes, disponível em versões para terminal e interface gráfica.

## 📋 Sobre o Projeto

O projeto permite cadastrar, listar, buscar, atualizar e excluir clientes. Os dados são armazenados localmente em arquivos de texto, sem necessidade de banco de dados.

Há duas versões independentes:
- **Terminal:** menu interativo com mensagens coloridas.
- **Interface gráfica:** janela feita com Tkinter, com formulário, tabela e busca.

> **Privacidade:** os arquivos armazenam dados em texto simples, sem criptografia. Use somente dados fictícios em testes e demonstrações; não armazene informações pessoais reais.

## 🚀 Acesse o projeto

Clone o repositório e entre na pasta do projeto:

```bash
git clone https://github.com/devgabrielporto07/Sistema-Cadastro-Clientes.git
cd Sistema-Cadastro-Clientes
```

É necessário ter Python 3.10 ou superior. O Tkinter deve estar disponível na instalação do Python para usar a versão gráfica.

**Versão para terminal:**

```bash
python sistema-cadastro-cliente.py
```

**Versão com interface gráfica:**

```bash
python Interface-Tkinter/sistema-cadastro-cliente-tkinter.py
```

Cada versão usa seu próprio arquivo `.txt` para salvar os dados, na pasta correspondente ao script.
